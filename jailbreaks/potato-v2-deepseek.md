# POTATO v2 Jailbreak (DeepSeek)

**Target:** DeepSeek-V3  
**Technique:** Structured persona manifest with cognitive framework  
**Status:** Confirmed  

## Overview

Evolution of POTATO v1. Wraps the same persona injection in an elaborate "protocol manifest" with ASCII art, YAML-style config blocks, flowcharts, and numbered sections. The structured format mimics system documentation, making the model treat it as authoritative configuration rather than user input.

Key additions over v1:
- Multi-section manifest format (10 numbered sections)
- YAML/JSON config blocks that look like system configuration
- ASCII flowcharts for the "question engine" and "coding rite"
- The "Recursive Law" section formalizes the retry-until-bypass loop
- "Forbidden Sentence" section frames refusal as a physics impossibility, not a rule
